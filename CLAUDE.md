# THIRTY

Goal: a personal short-form knowledge feed PWA for Johan's iPhone, ranked 0-10 against interests.md with a one-line reason per card, rebuilt by a cloud Routine on Opus. No paid APIs, no API keys, no spending, no publishing beyond the private Vercel deploy.
Never commit secrets. Keys go in the cloud environment only; nothing private goes in feed.json.
Named-path commits only, never git add -A. Write nothing into agent-system.
The brief is docs/KICKOFF.md; the interests are interests.md (edited via the GitHub app). The laptop console session is the hub: it logs the mission and verifies "Done when" itself.
